# YZMakalah V3 Premium

Kit untuk membantu mahasiswa menyusun makalah akademik berbahasa Indonesia bersama Claude, dari topik sampai file siap cetak. Referensi diambil dari sumber yang benar-benar ditemukan, bukan dikarang AI.

Dibuat oleh **YZ PROJECT** · Instagram [@yzproject24](https://instagram.com/yzproject24)

## Fitur

- **Referensi nyata:** jurnal nasional, jurnal internasional, dan buku akses terbuka yang memiliki DOI.
- **Mode Hemat:** rekomendasi 10 referensi untuk akun Free, dengan satu formulir dan instruksi per tahap.
- **Umur referensi:** dapat dipilih, maksimal 10 tahun terakhir.
- **Gaya sitasi Zotero:** lebih dari 10.000 gaya CSL, termasuk APA, IEEE, dan Turabian 8 Full Note.
- **Catatan perut atau catatan kaki:** sesuai gaya yang dipilih.
- **Tabel bukti:** setiap kutipan dicatat bersama sumber dan lokasinya.
- **Pemeriksaan naskah:** menolak kutipan yang diketik manual dan frasa klise.
- **Bekal presentasi:** ringkasan, alur bicara, istilah penting, dan latihan tanya jawab.

## Hasil

- Makalah dalam format Word dan PDF siap cetak
- Tabel bukti dan analisis referensi dalam format Excel
- Tautan referensi, atau ZIP PDF lewat jalur Google Colab
- Bekal presentasi dalam format PDF

## Cara Pakai

1. Unduh `YZMakalahV3Premium.zip`.
2. Kirim ZIP ke chat Claude Sonnet atau model di atasnya. Fitur eksekusi kode dan pembuatan file harus aktif.
3. Ketik: `Baca file BACA_DULU di ZIP ini. Kode saya: <kode aktivasi>`
4. Isi formulir yang muncul, lalu tunggu file selesai dibuat.

Kode aktivasi diperoleh dari YZ PROJECT.

### Jika kuota habis

Saat kuota pulih, kirim `lanjut` di chat yang sama.

### Jika perlu file PDF referensi

Pilih jalur Google Colab pada formulir. Jalur ini memberi file PDF dan pengecekan otomatis, tetapi memakai lebih banyak langkah dan kuota.

## Batasan

- Hasil tetap wajib dibaca dan diperiksa oleh penulisnya.
- Pada jalur tautan, kecocokan kutipan dinilai AI dan tidak dicek otomatis ke file PDF.
- Angka kemiripan bukan hasil Turnitin. Gunakan alat pengecekan dari kampus.
- Kit ini tidak dirancang untuk mengelabui detektor AI atau plagiarisme.
- Mutu jurnal perlu dinilai sendiri, karena status SINTA dan Scopus tidak diperiksa.
- Alur lengkap di akun Free masih dalam pengujian, dan kuota bisa habis sebelum makalah selesai.
- Kit dirancang untuk Claude. Dukungan untuk AI lain belum diuji.
